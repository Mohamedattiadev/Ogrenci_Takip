# API v1 referansı

Temel adres: `http://localhost:3001/api/v1` · Etkileşimli dokümantasyon: `http://localhost:3001/docs` · Makine tarafından okunur şema: [`openapi.json`](./openapi.json) (`pnpm --filter @yoklama/api openapi:dump` ile güncellenir).

## Kurallar

- **Kimlik doğrulama:** `Authorization: Bearer <accessToken>`. Erişim jetonu 15 dakika, yenileme jetonu 30 gün geçerlidir. Yenileme jetonu tek kullanımlıktır (her `refresh` yeni çift döner).
- **Yetki:** rol kontrolü API'de (CASL), veri kapsamı PostgreSQL RLS'te. Sistem yöneticisi her şeyi, yurt yöneticisi kendi yurdunu, hoca yalnızca görevlendirildiği yurt + burs programındaki derslerini ve öğrencilerini görür.
- **Yurt seçimi:** kayıt oluştururken yurt yöneticisinin yurdu jetondan alınır. Sistem yöneticisi `institutionId` göndermek zorundadır.
- **Listeler:** `?page=1&pageSize=25&search=...` (pageSize en fazla 100). Yanıt: `{ data: [...], meta: { page, pageSize, total, totalPages } }`. Alt listeler (grup üyeleri, grup geçmişi) düz dizi döner.
- **Tarihler:** gün hassasiyetindeki alanlar `YYYY-AA-GG`. "Bugün" Türkiye saatine göre hesaplanır. Günler `0 = Pazartesi … 6 = Pazar`, saatler `SS:DD`.
- **Silme:** öğrenci, kullanıcı, grup ve yurt yumuşak silinir; yoklama geçmişi korunur. Başarılı silme `204` döner.
- **Hatalar:** `{ statusCode, error, message, path, timestamp }`.
  - `400`: doğrulama hatası.
  - `401`: jeton eksik veya geçersiz.
  - `403`: yetki yok.
  - `404`: kayıt yok veya görülemiyor.
  - `409`: çakışma (aynı saatte ders, yoklaması girilmiş dersi iptal vb.).
  - `422`: veritabanı kuralı (cinsiyet/yurt uyuşmazlığı, yanlış burs programı vb.).
  - `429`: çok fazla istek.

**Öğrenci girişi:** öğrenci kullanıcı adıyla (`POST /auth/login` alanı `email` e-posta veya kullanıcı adı kabul eder) girer. Geçici şifreyle girişte jeton `mustChangePassword` taşır ve `PATCH /auth/me/password` dışındaki istekler `403` döner. Öğrenci silinir veya yurttan ayrılırsa hesabı kapanır, oturumları sonlanır.

Yoklama durumları: `PRESENT` (Geldi), `LATE` (Geç geldi), `EXCUSED` (İzinli), `ABSENT` (Gelmedi), `ABSENT_EXCUSED` (Haberli devamsız), `ABSENT_UNEXCUSED` (Habersiz devamsız). Devam yüzdesi = (Geldi + Geç geldi) / girilen kayıt.

## Tipik akış

1. Sistem yöneticisi yurt, burs programı ve kullanıcıları oluşturur, hocaları `teacher-assignments` ile yurt + programa görevlendirir.
2. Yurt yöneticisi dönem (`terms`), grup, ders ve haftalık programı (`schedules`) oluşturur, öğrencileri Excel'den aktarıp gruplara ekler.
3. Dönem başında `POST /sessions/generate` ile ders günleri üretilir. Tatiller otomatik atlanır.
4. Hoca `GET /sessions/today` ile dersini seçer, `GET /sessions/:id/attendance` listesiyle yoklama alır (`PUT` veya `all-present`).
5. Yönetici `GET /sessions?attendance=missing` ve raporlarla takibi yapar.
